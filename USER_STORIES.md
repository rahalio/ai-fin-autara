# Autara — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Retail customer

- As a customer, I want Autara to pay recurring bills and sweep surplus to savings within my rules, so that routine money tasks stop competing with my attention.
- As a customer, I want a clear explanation before any refinance or provider switch, so that I am not surprised by a silent move.
- As a customer, I want to pause all automation instantly, so that I regain control during a life shock (job loss, medical event).

### Financial coach / adviser

- As an adviser, I want a queue of material recommendations awaiting review, so that complex moments still get human judgment.
- As an adviser, I want the same rationale the customer sees, so that I am not reconciling two different stories.

### Conduct and model-risk officer

- As a conduct officer, I want every auto-executed action tied to a policy version and suitability check, so that we can evidence fair treatment.
- As a model-risk officer, I want to block promotion of a new optimisation model until monitoring thresholds pass, so that we do not ship ungoverned behaviour.
- As a conduct officer, when a customer complains that an automated switch harmed them, I want automation frozen and the decision packet preserved, so that redress is factual.

### Product and experience owner

- As a product owner, I want outcome dashboards (fees avoided, retention) rather than only engagement metrics, so that we prove Finding 2 loyalty value instead of vanity usage.
- As a product owner, I want to configure which action types are auto versus confirm-by-segment, so that we expand autonomy only as trust is earned.

### Platform administrator

- As a platform administrator, I want an inventory of third-party data and model providers with kill-switches, so that a vendor outage does not leave half-executed switches.
- As a platform administrator, I want audit exports of rationales and overrides for a regulated sample, so that supervisors can examine self-driving behaviour.
